# Antiphon — the elevator version

A personal music recommender that lives entirely in Markdown.

No application code — a handful of `.md` files turn Claude Code into
a music agent that reads your real last.fm history every session and
recommends music grounded in what you actually listen to, not what an
algorithm thinks you should.

Long tail respected. Every pick cites its reasoning. Nothing is
cached, nothing leaves your machine. Fork it, drop your last.fm
username and API key into two files, you're running in under a
minute.
